# SocialTwin AI — Azərbaycan dilində frontend prototipi

Bu layihə yalnız frontend-dir və Netlify kimi statik hostinq xidmətlərinə yerləşdirmək üçün hazırlanıb.

## Fayllar
- `index.html` — səhifənin strukturu
- `style.css` — dizayn və mobil uyğunlaşma
- `app.js` — demo qarşılıqlı əlaqələr

## Lokal açmaq
`index.html` faylını brauzerdə açmaq kifayətdir.

## Netlify-də yerləşdirmək
1. ZIP faylını çıxart.
2. `socialtwin-az` qovluğunu aç; `index.html`, `style.css` və `app.js` həmin qovluqda olmalıdır.
3. https://app.netlify.com/drop səhifəsinə daxil ol.
4. `socialtwin-az` qovluğunu sürükləyib səhifəyə burax.
5. Netlify yayımlama tamamlandıqdan sonra sayt üçün link verəcək.

## Vacib qeyd
Bu, təqdimat üçün frontend prototipidir. Real AI modeli, istifadəçi hesabları, server, canlı imkan bazası və məlumatların daimi saxlanması qoşulmayıb. Uyğunluq və hazırlıq faizləri nümunə göstəricilərdir. İmkan kartlarındakı keçidləri rəsmi məlumatı yoxlamaq üçün istifadə edin.
